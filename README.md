# indexly

## AI-Powered Video Search Engine

indexly makes large video libraries searchable by both what was said and what was shown.

Users can upload multiple videos and search using natural-language queries. indexly returns relevant video moments with timestamps, transcript snippets, thumbnails, visual matches, and AI-generated summaries.

### Core Features

* Video upload and ingestion
* Automatic transcription with timestamps
* Semantic search across transcripts
* Timestamp-based video playback
* AI-generated summaries
* Visual search using frame sampling and OCR
* Chart and slide detection
* Combined text + visual search
